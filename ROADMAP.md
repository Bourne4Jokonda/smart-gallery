# Карта проекта — Smart Gallery

> Обновлено: 04.10.2026. Статус: рабочий MVP в продакшене.
> Цель: довести до первой платной услуги для фотографа.

## Текущее состояние (ГОТОВО в продакшене)

- Публичный URL: https://aleksandr-faraonov.vercel.app
- Репозиторий: Bourne4Jokonda/smart-gallery, ветка main
- Стек: TanStack Start + React + Vite + Firebase (Firestore/Auth) + Cloudinary
- Cloudinary preset: smart-gallery
- Firebase project: smart-gallery-75599

### Что уже работает
- Регистрация / вход (Firebase Auth)
- Загрузка папки или файлов (до 2000 файлов, до 20 МБ каждый)
- Создание сессии (shoot) с UUID
- Личный кабинет: список съёмок, статистика
- Открытие сессии, просмотр сеткой
- Лайтбокс: навигация, скачивание фото, скачивание ZIP
- Фильтр "Все / Лучшие" (segmented toggle в sticky header)
- Прогресс: "X% оценено · Y% ошибок · Z% не оценено"
- AI-отбор кадров через Gemini 2.5 Flash (бесплатный API, оценка 1–10)
- Публичная ссылка на сессию (public-gallery)
- Удаление сессии из кабинета (реальное удаление из Firestore + Cloudinary)
- Удаление поштучно фото из Cloudinary
- Очистка папки Cloudinary целиком
- Кросс-устройственный синк (сессия с одного устройства видна на другом)
- Защита от дублей при загрузке (guard + фиксированный ID = shootId)

### Последние фиксы
- Удаление реально удаляет документ из Firestore (было только очистка полей)
- Удаление вызывает /api/delete-shoot → чистит Cloudinary
- saveShootRecord пишет по фиксированному ID (shootId), а не addDoc со случайным ID — убраны дубли сессий

## Проблемы / ограничения сейчас

- AI-отбор на бесплатной модели — не является ценностью, за которую платят
- Нет выбора избранного клиентом
- Нет пароля на публичную галерею
- Нет водяного знака
- Нет оплаты / печати / файлов
- Нет бренда фотографа в публичной галерее

## Roadmap (что дальше)

### Этап 1 — Клиентская галерея (ближайший MVP, 1 день)
- Публичная галерея с паролем
- Водяной знак / логотип фотографа
- Клиент отмечает "избранное"
- Ссылка для скачивания избранного
- Цель: первая продажа как услуга (разово 3 000–10 000 ₽ за съёмку)

### Этап 2 — Автопродажа
- Клиент выбирает файлы/печать, оплата (ЮKassa/СБП)
- Фотограф получает деньги без посредников
- Подписка 1 000–3 000 ₽/мес или % с заказа

### Этап 3 — AI-отбор как готовый результат
- Удаление дубликатов и брака
- Группировка по позам
- "10 лучших для портфолио"
- Ч/б версия
