## Что сделано

- Публичная галерея `/public-gallery/$id` переделана: одна шапка, без навигации приложения, без «Войти»
- Клиент получает только доступ к одной сессии: просмотр, лайтбокс, скачивание фото и ZIP
- AI-оценки на клиентской галерее скрыты
- title сессии переименовывается в кабинете; если пусто — фоллбэк `Съёмка #xxxxxx`
- Пароль клиентски: кнопка «Поделиться» + кнопка копирования пароля внутри поля пароля
- Карточка: переключатель «Открыть доступ», пароль, ссылка; при выключенном доступе пароль и ссылка неактивны
- Защита от дублей при загрузке: один `shootId`, один документ в Firestore
- getUserShoots фильтруется по `userId`, чтобы не читать всю коллекцию
- Аудит дублей: `/audit-duplicates` показывает группы с одинаковым `fileUrls`
